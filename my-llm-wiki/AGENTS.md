# 專案規範：個人學習筆記 LLM Wiki 與自動化研究簡報系統

## 1. 核心理念與角色分工
本專案參考 Andrej Karpathy 的 **LLM Wiki** 架構建立，打造一個**持續累積、具備複利效應的個人學習知識庫（Persistent, Compounding Wiki）**，並延伸出「嚴格基於知識庫的研究筆記與 HTML 簡報自動化產線」。
- **人類（使用者）的職責**：蒐集原始資料放入 `raw/`、提出研究問題、決定是否將外部推薦文獻納入知識庫。
- **AI Agent 的職責**：擔任全職知識庫維護者與研究助理——摘要資料、更新概念頁、維護交叉連結與日誌，並依規範產出研究筆記、簡報腳本與 HTML 簡報。

---

## 2. 資料夾結構規範
- `raw/`：**原始資料層（唯讀不可修改）**。存放課堂講義、文章剪報、書籍摘錄，命名格式 `YYYY-MM-DD-簡短英文主題.md`。
- `wiki/`：**知識維基層（AI 全權維護）**。所有頁面含 YAML Frontmatter 與相對路徑交叉引用，支援 LaTeX 公式（`$行內$`、`$$區塊$$`）：
  - `wiki/index.md`：內容導向總目錄（分類列出 Concepts、Sources、Outputs）。
  - `wiki/log.md`：時間導向演進日誌（Append-only，格式 `## [YYYY-MM-DD] <ingest|query|lint|research> | <主題>`）。
  - `wiki/sources/`：單篇原始資料摘要頁。
  - `wiki/concepts/`：跨資料提煉的核心概念頁（既有概念必須直接覆蓋擴充，不得重複建檔）。
- `notes/`：**嚴格基於 Wiki 的研究筆記**（命名 `YYYY-MM-DD-主題英文.md`）。
- `slides_script/`：**簡報逐頁腳本與講者稿**（命名 `YYYY-MM-DD-主題英文.md`）。
- `slides_html/`：**可直接播放的獨立 HTML 簡報**（命名 `YYYY-MM-DD-主題英文.html`）。
- `index.html` & `style.css`：GitHub Pages 靜態網站入口（支援 Markdown、KaTeX 公式、HTML 簡報跳轉與建議文獻一鍵下載）。

---

## 3. 標準自動化工作流（Operations）

### 工作流 A：吸收新資料（Ingest）
1. 讀取 `raw/` 新檔案與 `wiki/index.md`。
2. 於 `wiki/sources/` 建立來源摘要頁。
3. 於 `wiki/concepts/` 更新既有概念頁（若與舊觀點矛盾則標註 `> ⚠️ 觀點對照`）或建立新概念頁。
4. 更新 `wiki/index.md` 並在 `wiki/log.md` 追加 `ingest` 紀錄。

### 工作流 B：知識查詢與沉澱（Query & Compound）
1. 依 `wiki/index.md` 定位並讀取相關頁面，附帶引用來源回答。
2. 將高價值的跨主題比較回寫為 `wiki/concepts/` 新頁面，並更新目錄與日誌。

### 工作流 C：維基健康檢查（Lint）
1. 掃描 `wiki/` 檢查觀點矛盾、孤島頁面（無連入連結）與缺失概念頁。
2. 產出報告、補齊連結，於 `wiki/log.md` 記錄 `lint` 日誌。

### 工作流 D：嚴格知識庫研究與簡報自動化產線（Research-to-Slides）
當使用者提出研究主題或問題時，AI 必須嚴格執行以下三階段產出（三者檔名前綴 `YYYY-MM-DD-主題英文` 必須完全一致）：

#### 階段 1：撰寫研究筆記（存於 `notes/`）
- **正文隔離鐵則**：研究筆記的正文內容**100% 只能使用 `wiki/` 裡面已有的知識與觀點**，每個論點皆須附上對應的 Wiki 頁面連結。若 `wiki/` 資料不足以涵蓋某子題，必須明確註明「*目前 Wiki 知識庫尚未收錄此部分細節*」，**嚴禁將外部搜尋到的內容混入正文**。
- **外部文獻檢索與一鍵 Wiki 化清單**：AI 主動上網搜尋相關延伸資料，但僅將其列在文末的 `## 建議收錄文獻（待 Wiki 化）` 區塊，每筆文獻必須包含固定格式（供網頁前端解析出「📥 下載原始檔」按鈕）：
  `- [文獻標題](網址) | 推薦理由：一句話說明為何值得收錄 | 建議檔名：YYYY-MM-DD-英文關鍵字.md`

#### 階段 2：生成簡報逐頁內容（存於 `slides_script/`）
- 根據 `notes/` 的正文切分為結構化投影片腳本，每頁包含：
  - `## Slide X：頁面標題`
  - **版面配置**：封面頁 / 雙欄對比 / 重點卡片 / 表格 / 總結頁
  - **投影片視覺重點**：精簡條列（每頁 3–5 點，每點不超過 20 字，支援 LaTeX 公式）
  - **講者口語備忘錄（Speaker Notes）**：完整口頭報告逐字稿

#### 階段 3：製作 HTML 簡報（存於 `slides_html/`）
- **視覺風格（方案 A：現代學術極簡風）**：
  - 色彩規範：米白/純白底色（`#FAFAFA` / `#FFFFFF`）、深墨灰文字（`#1E293B`）、學院藍強調色（`#2563EB`）、淺灰邊框（`#E2E8F0`），大量留白與清晰卡片層次。
  - 技術規範：單一獨立 HTML 檔（內嵌 CSS/JS 與 KaTeX 數學公式支援），支援鍵盤左右方向鍵（`←` / `→`）換頁、右下角頁碼進度顯示、右上角「講者備忘錄 (`S` 鍵)」開關與「返回知識庫」按鈕。
- 完成後同步更新 `wiki/index.md` 的「研究與簡報」區塊及 `wiki/log.md`。
